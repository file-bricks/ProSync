1. EXECUTIVE VALUE PROPOSITION
--------------------------------------------------------------------------------
ProSync is an intelligent, high-performance desktop backup and folder synchronization
utility for Windows, Linux, and macOS with automated SQLite WAL database protection.
It combines 5 synchronization modes (Mirror, Update, Two-Way, One-Way, Index-Only),
transactional SFTP remote upload capabilities, automated SQLite WAL checkpoints
(`PRAGMA wal_checkpoint(TRUNCATE)`), IANA-timezone-aware daily autosync schedules,
a batch sync execution queue, system-tray background automation, and a portable
companion export format (`prosync-profile-v1.json`) in a single native PySide6 (Qt 6)
application engineered with 100% local-first data isolation and zero cloud egress.


2. TARGET AUDIENCE & STAKEHOLDER PERSONAS
--------------------------------------------------------------------------------
Persona 1: Desktop Power Users & Windows Sysadmins
- Context: Regular automated backups of vital working directories, NAS shares, and external drives.
- Pain Point: Generic sync utilities either lack background tray operation, lack scheduling,
  or corrupt open SQLite databases during live copies.
- Benefit: Unobtrusive system-tray automation, IANA timezone-aware daily triggers, batch queues,
  and atomic folder synchronization with fail-closed safety.

Persona 2: SQLite & Database Application Developers
- Context: Development and production environments utilizing SQLite in WAL (Write-Ahead Logging) mode.
- Pain Point: Standard copy tools copy active database files while WAL transactions are uncommitted,
  producing inconsistent, corrupt, or unusable backup copies.
- Benefit: Automated pre-sync SQLite WAL checkpointing (`PRAGMA wal_checkpoint(TRUNCATE)`),
  defensive lock contention detection (fail-closed on SQLITE_BUSY), and automated WAL auxiliary file exclusion.

Persona 3: Privacy & Compliance Officers / DSGVO & Enterprise Auditors
- Context: Regulated industries, legal/medical records, and sensitive local file archives.
- Pain Point: Cloud storage clients and SaaS synchronization tools continuously exfiltrate telemetry
  and risk unauthorized data leaks.
- Benefit: Uncompromising 100% Local-First & Zero-Egress architecture; zero external telemetry;
  fully unprivileged user-mode execution (Non-Elevation / RunAsInvoker).

Persona 4: Automation Engineers & Multi-Agent Framework Architects
- Context: Headless execution, batch scripts, CI pipelines, and LLM-assisted tool pipelines.
- Pain Point: Inflexible GUI-only tools that cannot be scripted without window managers or user clicks.
- Benefit: Full-featured headless CLI (`--list`, `--run <id|name>`, `--all`, `--quiet`),
  redacted portable profile format (`prosync-profile-v1.json`), and comprehensive contract test suites.

5. GOVERNANCE & RUNTIME INVARIANTS (10 PILLARS)
--------------------------------------------------------------------------------
INV-LOCAL-01: 100% Offline & Zero-Egress Privacy
  Pure local runtime. Zero network sockets opened to telemetry or analytics endpoints.
INV-SEC-02: Unprivileged RunAsInvoker Non-Elevation
  Standard unprivileged user mode. Never prompts for UAC elevation or root credentials.
INV-WAL-03: SQLite WAL Crash-Consistent Checkpoint Guard
  Automated `PRAGMA wal_checkpoint(TRUNCATE)` prior to file transfer; aborts fail-closed on lock contention.
INV-MODES-04: Deterministic 5-Mode Synchronization Engine
  Clear semantic separation: mirror, update, two_way, one_way, and index_only.
INV-SFTP-05: Atomic SFTP Uploads & Rollback Safety
  Remote SFTP uploads use atomic staging and roll back failed or incomplete transfers.
INV-SCHED-06: IANA Timezone-Aware Daily Scheduling
  Deterministic execution across daylight saving time (DST) shifts with no catch-up storms.
INV-QUEUE-07: Batch Synchronization Execution Queue
  Sequential multi-connection batch execution with granular progress and status reporting.
INV-EXP-08: Redacted Portable Profile Export (`prosync-profile-v1.json`)
  Exported profiles redact absolute local paths and credentials for mobile companion inspection.
INV-ACC-09: Screen Reader Accessibility & Keyboard Shortcuts
  AccessibleName, AccessibleDescription, and status indicators across all primary controls.
INV-SLA-10: 48-Hour Security Response & 5-Day Triage SLA
