Short description:
データベース保護、一括同期、秘匿化プロファイル出力対応のローカル同期・バックアップツール。

Description:
ProSync は、SQLite や Access データベースの安全なバックアップに特化したローカルファイル・フォルダ同期デスクトップアプリケーションです。クラウドを介さず、ローカルパスやネットワーク共有上で直接動作し、定期的な同期処理を透明かつ確実に実行します。

- ローカルパスおよびネットワーク共有に対応したフォルダ同期
- 個別ファイルおよびデータベースの確実な保護
- SQLite/Access の自動認識と WAL 安全処理
- 複数接続の一括バッチ実行
- システムトレイ常駐によるバックグラウンド定期バックアップ
- カウンタとタイムスタンプを含むローカル同期レポート
- 実パスや認証情報を除外した `prosync-profile-v1.json` の安全なプロファイル共有

Audience:
ローカル環境のプロジェクトフォルダ、ドキュメント、データベースを定期的にバックアップ・同期したい開発者、フリーランス、システム管理者。

Keywords:
バックアップ, 同期, ファイル同期, フォルダ同期, sqlite, データベース保護, 一括同期
