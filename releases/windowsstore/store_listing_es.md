Short description:
Herramienta local de copia y sincronización con protección de bases de datos y exportación.

Description:
ProSync es una aplicación de escritorio local para la sincronización de archivos y carpetas con especial atención a las copias de seguridad de bases de datos SQLite y Access. Opera directamente con rutas locales o recursos compartidos de red y permite ejecutar tareas de sincronización periódicas de forma transparente y predecible.

- Sincronización de carpetas para rutas locales y recursos compartidos
- Sincronización de archivos individuales y bases de datos críticas
- Protección de SQLite y Access con gestión segura de WAL
- Sincronización por lotes para múltiples conexiones seleccionadas
- Copias de seguridad programadas en segundo plano desde la bandeja del sistema
- Informes de sincronización locales con recuentos y marcas de tiempo
- Exportación de perfiles redigidos `prosync-profile-v1.json` sin rutas locales ni secretos

Audience:
Desarrolladores, profesionales independientes, administradores de sistemas y equipos que necesitan respaldar o sincronizar carpetas de proyectos y bases de datos locales.
