Short description:
Локальный инструмент резервного копирования и синхронизации с защитой БД и экспортом.

Description:
ProSync — это настольное приложение для локальной синхронизации файлов и папок с расширенной защитой баз данных SQLite и Access. Программа работает напрямую с локальными путями и сетевыми папками, обеспечивая прозрачное и надежное резервное копирование.

- Синхронизация папок для локальных путей и сетевых ресурсов
- Защита отдельных файлов и критически важных баз данных
- Распознавание SQLite и Access с безопасной обработкой WAL
- Пакетная синхронизация нескольких выбранных подключений
- Расписание резервного копирования с работой в системном трее
- Локальные отчеты с подсчетом скопированных и пропущенных файлов
- Безопасный экспорт профилей `prosync-profile-v1.json` без конфиденциальных данных

Audience:
Разработчики, фрилансеры, администраторы и пользователи, которым требуется надежное и безопасное резервное копирование файлов и баз данных.
